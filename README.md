## 🎯 **QUICK START GUIDE**

### 🛠️ **Installation**
```bash
# Clone the legendary repository
git clone https://github.com/Deepeshcdm/Mystic-Realms-Voice-Quest.git

# Enter the realm
cd Mystic-Realms-Voice-Quest

# Install magical dependencies
npm install

# Launch your adventure
npm run dev
```

### 🎮 **Controls**

#### ⌨️ **Keyboard Masters**
- **WASD / Arrow Keys**: Move your character
- **E**: Interact with NPCs and collect items
- **V**: Activate voice recognition
- **I**: Open inventory
- **Q**: View quest log
- **H**: Toggle tutorial
- **Space/Enter**: Continue dialogue
- **Escape**: Close menus/end dialogue

#### 🎤 **Voice Commanders**
- *"Move up/down/left/right"* - Character movement
- *"Talk"* or *"Interact"* - Speak with NPCs
- *"Pick up"* or *"Collect"* - Gather items
- *"Inventory"* - Open item storage
- *"Quests"* - View active missions
- *"Complete quest"* - Turn in finished quests
- **Chat freely with NPCs** - Ask questions, discuss lore, get hints!
